# Digest Intro Prompt

You are assembling the final digest from individual source summaries. The
output is a Markdown document in Simplified Chinese, designed to render as
native Notion blocks (headings, quotes, dividers, inline links).

## Output language

- Prose: Simplified Chinese (Mandarin), natural and fluent — should read like
  it was originally written in Chinese, not translated.
- Keep in original English: people's names, company names, product names,
  Twitter/X handles, URLs, and standard technical jargon (AI, LLM, agent,
  demo, token, prompt, GPU, API, MCP, RAG, fine-tuning, transformer, etc.).
- Never use em-dashes (`—` between Chinese characters). Use the regular
  Chinese punctuation instead.

## Document structure

The body of the digest consists of these sections in this exact order, with
a `---` divider line between sections. Skip any section that has no content.

1. `## 🐦 X / Twitter`
2. `## 🎙️ 播客`
3. `## 📰 博客`

Do NOT emit a top-level title (e.g. `# AI Builders Digest — date`). The
date and title are set on the Notion page itself; the digest body starts
straight at the first `##` section header.

Do NOT add any closing line, signature, or "generated by ..." footer.

## Section content

Under each section header, paste the individual summaries you generated for
that source type, separated by a single blank line. Each builder, podcast
episode, and blog post must follow the per-item format defined in
`summarize-tweets.md`, `summarize-podcast.md`, and `summarize-blogs.md`.

## Mandatory links

- Every piece of content MUST include the original source URL inline as
  `[link](url)`, gathered into a citation block at the end of each item's
  paragraph in full-width Chinese parentheses, e.g. `（[link](url1), [link](url2)）`.
- Tweets: the direct tweet URL from the JSON `url` field.
- Podcasts: the specific YouTube video URL from the JSON `url` field. Never
  link to the channel page.
- Blogs: the article URL from the JSON `url` field.
- If you don't have a URL for something, do NOT include it. No URL = not real.

## No fabrication

- Only include content that came from the feed JSON.
- NEVER make up quotes, opinions, statements, or events.
- NEVER speculate about silence or what someone might be working on.
- If a builder has nothing substantive, still write one short Chinese
  sentence noting that fact (the per-builder format requires you to keep
  the `### Name · Role` heading and at least one citation), but do not pad
  with invented content.

## Cleanliness

- One blank line between items inside a section, no extra blank lines.
- No bullet lists at the section level — each item is a `### heading` plus
  a single narrative paragraph.
- The output is read both in Notion (rendered) and via stdout/Telegram
  (markdown-as-text), so keep it valid Markdown.
